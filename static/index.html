🧮 HalluScore Formula

A novel composite metric combining NLI, semantic similarity, LLM judgment, and factuality signals.

HalluScore =
  w₁ × NLI_score +
  w₂ × Semantic_score +
  w₃ × LLM_judge_score +
  w₄ × Factuality_bonus

Default: 0.35 + 0.20 + 0.30 + 0.15

🔬 Component Models

  • NLI cross-encoder/nli-deberta-v3-base — entailment prediction between context and each sentence of the generated text
  • SEM all-MiniLM-L6-v2 — BERTScore-style precision/recall/F1 via embedding similarity
  • LLM Gemini 1.5 Flash — LLM-as-judge for reasoning-level hallucination detection
